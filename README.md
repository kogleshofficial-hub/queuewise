# QueueWise

Know the queue before you go.

QueueWise is a crowdsourced waiting-time platform designed to help people make better decisions about when to visit busy real-world services. It starts with community-reported queue conditions and is designed to scale globally.

## Principles

- Real community reports, never fabricated live data.
- Clear timestamps and confidence indicators.
- Old reports expire from live estimates.
- Privacy-first reporting.
- Accessible and mobile-friendly.
